# prd.md — 업무 관리 웹 프로그램 MVP
## 문제
업무가 메모지·메신저·이메일에 흩어져 마감 지난 업무와 긴급 업무를 한눈에 볼 수 없다.
## 사용자
서버·회원가입 없이 자기 브라우저에서 업무를 관리하는 개인 1명.
## 범위(MVP)
FR-01 업무 등록 / FR-02 목록 조회 / FR-03 수정 / FR-04 완료·완료 취소 / FR-05 삭제(확인) / FR-06 검색·필터 / FR-07 LocalStorage 저장·복원 / FR-08 JSON 백업 내보내기·가져오기
## 제외(이번 장에서 만들지 않음)
다중 사용자, 로그인, 서버 동기화, 알림, 첨부파일, 설치형 앱(→ 제11장)
## 수용 기준
AC-01~AC-12는 test-cases.md에서 관찰 가능한 결과로 확인한다.
