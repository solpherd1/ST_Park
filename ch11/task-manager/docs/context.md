# context.md — 공통 규칙
- 기술: HTML, CSS, 순수 JavaScript. 프레임워크·빌드 도구·외부 라이브러리 금지.
- 파일: index.html, style.css, app.js 세 개만 수정한다. 모든 경로는 상대 경로(./)로 쓴다.
- 데이터 기준은 `tasks` 배열 하나. 변경 후에는 반드시 `commit()`(저장+렌더링)을 호출한다.
- 사용자 입력은 `textContent`로만 표시한다. `innerHTML`에 사용자 입력 금지.
- LocalStorage에 비밀번호, API Key, 실제 개인정보 저장 금지.
- 저장 키와 스키마 버전을 AI가 임의로 바꾸지 않는다. 바꿀 때는 마이그레이션 계획을 먼저 제출한다.
- 요청받지 않은 기능(로그인, 서버, 알림, 첨부파일) 추가 금지.
- 작업 하나 = Git 커밋 하나. 커밋 메시지에 작업 ID를 쓴다.
