# 업무 관리 웹 프로그램 (제10장 실습 결과물)

## 목적
한 사람이 자기 브라우저에서 업무를 등록·조회·수정·완료 처리하고, 상태·우선순위·마감일·검색어로 필터링하는 최소 업무 관리 도구이다.

## 실행 방법
1. 이 폴더를 VS Code로 연다.
2. Live Server 확장으로 `index.html`을 연다(주소가 `http://127.0.0.1:5500/` 형태). 또는 터미널에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/`에 접속한다.
3. `index.html`을 더블클릭해 `file://`로 열어도 동작하지만, 저장 위치가 달라지고 제11장의 Service Worker는 동작하지 않으므로 로컬 서버 사용을 권장한다.

## 기능
- 업무 등록·수정·완료/완료 취소·삭제(확인 후)
- 검색어·상태·우선순위·마감일(오늘/기한 지남/없음) 필터, AND 결합, 필터 초기화
- LocalStorage 자동 저장, 손상 데이터 보관 후 빈 목록으로 시작
- JSON 백업 내보내기·가져오기(가져오기 전 현재 데이터 자동 백업)

## 저장 위치와 한계
- 저장 키: `ai-agent-designer.task-manager.v1` (스키마 버전 1)
- 같은 출처(프로토콜+도메인+포트)의 같은 브라우저에서만 보인다. 다른 기기·브라우저·포트와 동기화되지 않는다.
- 브라우저 데이터 삭제 시 사라진다. 정기적으로 JSON 백업을 내보낸다.
- 배포 주소를 바꾸면(예: 로컬 → GitHub Pages) 기존 데이터가 보이지 않는다. 백업 내보내기 → 새 주소에서 가져오기로 옮긴다.

## 개인정보 주의
실제 고객명·연락처·비밀번호·API Key를 입력하지 않는다. 실습은 가상 데이터로 한다.
